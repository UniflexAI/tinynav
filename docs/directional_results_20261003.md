# 输入与左右方向诊断（2026-10-03）

结论：这批输入完整进入模型，明确字段能改变死胡同的选择，但选择对选项顺序敏感，尚不能视为脱困能力提升。保留为离线实验，不接入在线控制。

## 1. 模型实际读到了什么

审计 7 个已有 v2 快照的 28 个独立问题提示词，复现部署中的格式化函数、tokenizer 和 thinking-off 聊天模板，保存完整文本、token IDs 与部署源码 SHA256。与 llama.cpp /tokenize 的 token IDs 一致。

- 每个原始问题为 1,873–3,794 tokens；当前每槽容量 4,096，两个槽。所有问题都能容纳提示词和一个输出 token。
- 一万多 input tokens 是多个独立问题的总和，不能据此认定单次上下文超长。
- 当前适配器为每个问题独立读取下一 token 的选项字母权重，按类型温度归一化；它不生成可供检查的推理过程。因此不能从权重倒推出模型内在原因。
- 历史日志有超过 4,096 tokens 被明确拒绝的记录；保留日志未找到 truncated=1。本次审计不保证所有过去或未来请求都完整。

明确字段的默认带空格 JSON 在死胡同提示词上最高达到 4,688 tokens，超出容量。因此采用紧凑 JSON 字符串，保留全部数据和原有数组 _index 标注，仅去除空格。紧凑明确字段最高为 3,858 tokens，仍使用原运行参数。

## 2. 信息表达改动

CSV 行转成 stage、blocked_fraction、unknown_fraction、near_past_path_fraction、recent_clear_fraction 等明确字段；端点字段也明确命名。增加由已有终点角度导出的 turn_direction 和字段定义。

说明机器人坐标 x 向前、y 向左、正 yaw 左转，world 坐标单独区分。recent.turned_deg 是累计绝对转角，不能解释为左转角。历史路线和中心连通性仍不能证明当前足迹安全；未知不变为已知。

未新增传感观测、候选或控制动作。planner、观测生成、执行器和安全检查均未修改。

## 3. 同快照三组对照与镜像

7 个快照，每个重复两次；原场景/左右镜像各测试原 JSON、仅压缩空格、压缩后明确字段，共 84 个请求。请求顺序轮换。所有提示词预检查容量、核对 tokenizer IDs，并逐请求验证返回 usage 等于复现渲染的 token 数。

| 场景 | 原表达（原场景） | 仅压缩空格（原场景） | 明确字段（原场景） |
| --- | --- | --- | --- |
| 死胡同 4 快照×2 | 8/8 不确定 | 8/8 不确定 | 8/8 左转探测 |
| L 转弯 3 快照×2 | 6/6 右转探测 | 6/6 右转探测 | 6/6 右转探测 |

死胡同明确字段在镜像后仍 8/8 左转。这个区域左右 pivot 的观测非常接近，镜像不能要求唯一相反的正确动作，也不能把结果直接判成几何错误。

L 转弯原表达镜像后 2/6 左转、4/6 不确定；仅压缩空格和明确字段均 6/6 左转，原场景均右转。但所有 L 转弯快照中 pivot 都只提供一个方向（原场景右、镜像左），因此这不是双侧候选竞争下方向判断可靠的充分证据。

| 场景 | 原表达中位耗时 | 仅压缩空格 | 明确字段 |
| --- | --- | --- | --- |
| 死胡同（含镜像） | 3.95 秒 | 3.50 秒 | 4.04 秒 |
| L 转弯（含镜像） | 3.56 秒 | 3.05 秒 | 3.58 秒 |

84 个请求均未超过 8 秒。只是离线 HTTP 耗时，在线调度与状态采集开销不包含在内。不得把选项权重当成成功率或安全概率。

## 4. 数值读取与选项顺序诊断

另做 28 个请求：每个原场景/镜像分别使用正常和反转的选项顺序，证据、选项 ID、说明和策略完全相同。每次独立评分两题：原 alternative 和“哪侧 planner 碰撞拒绝比例更低”。该事实题从报告 counts 计算期望答案，不代表足迹安全。

- 数值读取 28/28 正确：死胡同 16/16 识别相同比例；L 转弯 12/12 识别原右/镜像左的较低拒绝比例。
- 死胡同 8/8 顺序对照改变具体动作：正常顺序选左转，反转顺序选右转。
- L 转弯 0/6 顺序对照改变动作，仍保持原右/镜像左；单侧 pivot 可用性仍是限制。

这个结果直接表明：在这些近似对称的死胡同快照上，具体方向选择受选项排列影响。它不能证明模型完全不懂场景，也不能证明任一方向是错误或正确的脱困路径。明确字段让模型更愿意选动作，但目前缺少该选择可靠、有用的证据。
